# Movie Ticket Booking

## Payment Testing (Razorpay Test Mode)
This project uses Razorpay in test mode for the payment flow. Do not enter real card details.

To test payments:
1. Use Razorpay test card details or test UPI IDs from the official Razorpay documentation.
2. Complete the checkout and return to the app to see the verification step.

Razorpay test credentials and UPI IDs are listed here:
https://razorpay.com/docs/payments/payment-gateway/quick-integration/test-integration/
